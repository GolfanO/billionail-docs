**เครดิตสมาชิก** คือกระเป๋าเงินเป็นบาท ผูกกับเบอร์โทร ใช้ร่วมได้ทั้ง 3 สาขา  
ไม่ใช่แต้มสะสม และไม่ใช่ปุ่มแลกรางวัล

<Aside type="danger" title="อย่าสับสนกับแลกรางวัล">
อยากตัดแต้มให้บริการฟรี → ไปที่ [สะสมแต้ม](/crm/) แล้วกด **แลกรางวัล**  
อยากใช้เงินในกระเป๋าเครดิต → เลือก **Credit / แพ็กเกจ** ตามคู่มือนี้
</Aside>

## สองปุ่มที่ต้องแยกให้ขาด

| | **ซื้อเครดิต** (สินค้าเติมเงิน) | **ใช้ Credit / แพ็กเกจ** (จ่ายบิลบริการ) |
| --- | --- | --- |
| ลูกค้าทำอะไร | ซื้อเงินใส่กระเป๋า | เอาเงินในกระเป๋ามาจ่ายบริการ |
| เลือกพนักงานไหม | **ไม่เลือก** ไม่มีค่าคอม | เลือกพนักงานตามบริการตามปกติ |
| ได้แต้มไหม | **ไม่ได้แต้ม** | ได้แต้มจากยอดสุทธิของบริการตามสูตรปกติ |
| นับยอดวันไหม | เงินที่รับวันนี้ = รายได้ | การเผากระเป๋า **ไม่ใช่** ยอดเงินสดของวัน |
| มี 5% ไหม | ไม่มี | มี ถ้าใช้เครดิตแม้แต่บาทเดียว รวมบิลแยกจ่าย |

## ซื้อเครดิต (เติมกระเป๋า)

ใช้เมื่อลูกค้าอยากใส่เงินเข้ากระเป๋าล่วงหน้า

<Steps>

1. ใส่เบอร์โทรลูกค้าให้ถูกต้อง (กระเป๋าอยู่ที่เบอร์นี้ ใช้ได้ทั้ง 3 สาขา)

2. เลือกสินค้า **ซื้อเครดิต** ตามยอดที่ลูกค้าจ่าย

3. **อย่าเลือกพนักงาน** — สินค้านี้ไม่มีคนทำ ไม่มีค่าคอม

4. รับเงินสดหรือ QR ตามยอดซื้อ แล้วปิดบิล

</Steps>

บิลนี้คือรายได้ของร้าน + ยอดเข้ากระเป๋าลูกค้า  
บิลนี้ **ไม่ได้แต้มสะสม**

## ใช้เครดิตจ่ายบิลบริการ

จอชำระเงินเขียนว่า **Credit / แพ็กเกจ** (จอเก่าอาจยังเขียน Member)

### ลำดับคิดเงิน — ทำตามนี้ทุกครั้ง

<Steps>

1. **ใส่โปรร้านก่อน** — ส่วนลดร้าน โปรชิ้น โปรบิล ทำก่อนเสมอ

2. **ดูว่าจะใช้เครดิตไหม** — ถ้าใช้เครดิตแม้แต่บาทเดียว (รวมบิลที่เครดิตไม่พอแล้วเก็บส่วนต่างเป็นเงินสด) ให้ **บวก 5%**

3. **เผายอดจากกระเป๋า** — ระบบตัดเงินในกระเป๋าตามยอดหลังโปร + 5%

4. **ถ้าเครดิตไม่พอ** — เผาที่เหลือในกระเป๋า แล้วเก็บส่วนต่างเป็นเงินสดหรือ QR

</Steps>

<Aside type="tip" title="เงินสด/QR อย่างเดียว = ไม่บวก 5%">
ลูกค้ามีเครดิตเหลือ แต่เลือกจ่ายเงินสดหรือ QR ทั้งบิล และไม่แตะกระเป๋า → **ไม่บวก 5%** กระเป๋าไม่ขยับ
</Aside>

### ค่าคอมและแต้มตอนใช้เครดิต

- พนักงานได้ค่าคอมตาม **ราคาเต็มของบริการ** (ราคาลิสต์ ไม่ถูกลดเพราะใช้เครดิต)
- แต้มสะสมคิดจาก **ยอดสุทธิของบริการ** ตามสูตรปกติ หลังโปรร้าน — ดู [สะสมแต้ม](/crm/)
- การเผากระเป๋าไม่นับเป็นยอดเงินสดของวัน ยอดวันที่นับคือเงินที่รับจริงตอน **ซื้อเครดิต**

## ตัวอย่างสั้นๆ

**ตัวอย่าง 1 — ซื้อเครดิต**  
ลูกค้าโอน ฿2,000 ซื้อเครดิต  
รับเงิน ฿2,000 = รายได้วันนี้ กระเป๋าเพิ่ม ฿2,000 ไม่เลือกพนักงาน ไม่ได้แต้ม

**ตัวอย่าง 2 — ใช้เครดิตทั้งบิล**  
บริการราคาเต็ม ฿1,000 มีโปรร้าน 10% → เหลือ ฿900  
จ่ายด้วยเครดิต → บวก 5% → ยอดเผา ฿945  
กระเป๋าลด ฿945 พนักงานได้คอมจากราคาเต็ม ฿1,000 แต้มคิดจากยอดสุทธิบริการตามปกติ

**ตัวอย่าง 3 — เครดิตไม่พอ แยกจ่าย**  
ยอดหลังโปร + 5% = ฿945 กระเป๋ามี ฿400  
เผา ฿400 เก็บส่วนต่าง ฿545 เป็นเงินสด/QR  
ยังบวก 5% เพราะใช้เครดิตบางส่วน

**ตัวอย่าง 4 — มีเครดิตแต่จ่ายเงินสดทั้งบิล**  
กระเป๋ามีเงิน แต่ลูกค้าจ่าย QR ทั้งบิล ไม่ใช้ Credit / แพ็กเกจ  
ไม่บวก 5% กระเป๋าไม่ลด

**ตัวอย่าง 5 — ยกเลิกบิลที่เผาเครดิต**  
void บิลที่เผากระเป๋าแล้ว → เงินกลับเข้ากระเป๋าตามเดิม

## ห้ามทำ

- ห้ามใช้ **Credit / แพ็กเกจ** แทนปุ่ม **แลกรางวัล** — คนละระบบ
- ห้ามลืมบวก 5% เมื่อใช้เครดิตแม้แยกจ่าย
- ห้ามบวก 5% ถ้าลูกค้าจ่ายเงินสด/QR ทั้งบิลโดยไม่ใช้เครดิต
- ห้ามเลือกพนักงานบนสินค้าซื้อเครดิต และห้ามสัญญาว่าบิลเติมเงินได้แต้ม
- ห้ามนับยอดเผากระเป๋าเป็นเงินในลิ้นชักของวัน
- ห้ามแก้ยอดยกมาเอง — แคชเชียร์ไม่ปรับยอดเปิดบัญชี
- ห้ามสัญญาว่าเครดิตสาขานี้ใช้สาขาอื่นไม่ได้ — ใช้ร่วม 3 สาขาตามเบอร์

## สำหรับหัวหน้า / แอดมิน

แคชเชียร์ไม่ปรับยอดตั้งต้น  
ยอดยกมาใส่ที่ **CRM แต้ม → แท็บเครดิต (ยอดยกมา)** เท่านั้น

ถ้าบิลเผาเครดิตผิด ให้ void เพื่อคืนกระเป๋า อย่าให้แคชเชียร์เดายอดแล้วเติมมือ

<Aside type="note" title="รูปหน้าจอ — ใส่ทีหลังได้">
ยังไม่มีไฟล์ภาพในรีโปนี้ ใช้ลำดับขั้นตอนด้านบนกับจอ POS จริง  
ถ้าจะแปะรูปทีหลัง วางไฟล์ใน `src/assets/` แล้วใส่ภาพในหน้านี้
</Aside>
